# Auto Clicker

A simple Python-based auto-clicker built using PyAutoGUI. It automates mouse movement and clicking with customizable delay/wait times between actions.

## Features
- Automates mouse pointer movement
- Simulates mouse clicks
- Configurable wait/delay intervals between actions

## Tech Stack
- Python
- PyAutoGUI

## Usage
Run the script and the program will automatically move the mouse and perform clicks based on the defined wait times.
